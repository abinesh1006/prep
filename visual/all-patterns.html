Arrays & strings 7 patterns

Big-O

If you see: "n ≤ 10^5", "efficient", "can you do better?", any input-size limit in the constraints

Read the input limit first: it tells you which running time the interviewer expects, before you write any code.

// ~10^8 simple steps per second. From the limit on n:
// n ≤ 10       → O(n!)        n ≤ 20      → O(2^n)
// n ≤ 500      → O(n³)        n ≤ 10^4    → O(n²)
// n ≤ 10^6     → O(n log n)   n ≥ 10^8    → O(log n) or O(1)
for (int i = 0; i < n; i++)            // O(n)
  for (int j = i + 1; j < n; j++)      // inside it: O(n²) total
    count++;
for (int k = n; k > 1; k /= 2) steps++; // halving: O(log n)
Arrays.sort(a);                          // O(n log n)

Cost: Count loops: nested = multiply, one after another = add, halving = log n.

Classics: Two Sum · Contains Duplicate · Valid Anagram

The constraint is the hint: n tells you the Big-O.

Arrays & hashing

If you see: "seen before", "duplicate", "pair that sums to", "group by", "count frequency"

Store what you have already seen in a HashMap or HashSet so each later question ("have I seen X?") takes O(1) instead of a scan.

int[] twoSum(int[] nums, int target) {
  Map<Integer, Integer> seen = new HashMap<>();   // value -> index
  for (int i = 0; i < nums.length; i++) {
    Integer j = seen.get(target - nums[i]);       // the partner I need
    if (j != null) return new int[]{j, i};
    seen.put(nums[i], i);
  }
  return new int[0];
}

Cost: O(n) time, O(n) extra space.

Classics: Two Sum · Group Anagrams · Longest Consecutive Sequence

Trade memory for time: a map turns "search" into "look up".

Two pointers

If you see: "sorted array", "pair / triplet with sum", "in place", "palindrome", "from both ends"

Put one finger at each end of a sorted array and move the one that brings you closer to the goal; each step rules out a whole row of pairs.

int[] pairWithSum(int[] a, int target) {          // a is sorted
  int l = 0, r = a.length - 1;
  while (l < r) {
    int s = a[l] + a[r];
    if (s == target) return new int[]{l, r};
    if (s < target) l++;                          // need bigger
    else r--;                                     // need smaller
  }
  return new int[0];
}

Cost: O(n) time, O(1) space (plus O(n log n) if you must sort first).

Classics: Two Sum II · 3Sum · Container With Most Water

Sorted + pair → two fingers walking inward.

Sliding window

If you see: "longest / shortest substring or subarray", "at most K distinct", "contiguous", "window of size k"

Grow the window on the right; when it breaks the rule, shrink it from the left until it is valid again, and record the best size.

int lengthOfLongestSubstring(String s) {
  Map<Character, Integer> count = new HashMap<>();
  int best = 0;
  for (int l = 0, r = 0; r < s.length(); r++) {
    count.merge(s.charAt(r), 1, Integer::sum);     // grow right
    while (count.get(s.charAt(r)) > 1)              // rule broken
      count.merge(s.charAt(l++), -1, Integer::sum); // shrink left
    best = Math.max(best, r - l + 1);
  }
  return best;
}

Cost: O(n) time: each index enters and leaves the window once. O(k) space.

Classics: Longest Substring Without Repeating Characters · Longest Repeating Character Replacement · Minimum Window Substring

Right pointer explores, left pointer repairs.

Prefix sum

If you see: "sum of range i..j", "many range queries", "subarray sum equals K", negatives allowed

Keep running totals so any range sum is one subtraction; to count subarrays summing to K, look up how many earlier totals equal "now − K".

int subarraySum(int[] nums, int k) {
  Map<Integer, Integer> seen = new HashMap<>();
  seen.put(0, 1);                                 // the empty prefix
  int sum = 0, count = 0;
  for (int x : nums) {
    sum += x;
    count += seen.getOrDefault(sum - k, 0);       // earlier prefixes that fit
    seen.merge(sum, 1, Integer::sum);
  }
  return count;
}

Cost: O(n) time, O(n) space. Range query after building: O(1).

Classics: Range Sum Query - Immutable · Subarray Sum Equals K · Contiguous Array

sum(i..j) = pre[j+1] − pre[i]; remember to seed the map with 0.

Kadane

If you see: "maximum sum subarray", "best contiguous run", "max profit in one pass"

At each number decide: add it to the run you have, or start a new run here — whichever is bigger — and remember the best run ever seen.

int maxSubArray(int[] nums) {
  int cur = nums[0], best = nums[0];
  for (int i = 1; i < nums.length; i++) {
    cur = Math.max(nums[i], cur + nums[i]);       // extend or restart
    best = Math.max(best, cur);
  }
  return best;
}

Cost: O(n) time, O(1) space.

Classics: Maximum Subarray · Maximum Product Subarray · Maximum Sum Circular Subarray

A negative past only drags you down — drop it.

In-place tricks

If you see: "O(1) extra space", "without a copy", "rotate", "partition 0/1/2", "without division"

Rearrange inside the same array with a few pointers (Dutch flag), reversals (rotation) or left/right running products.

void sortColors(int[] a) {                        // values are 0, 1, 2
  int lo = 0, mid = 0, hi = a.length - 1;
  while (mid <= hi) {
    if (a[mid] == 0) swap(a, lo++, mid++);        // 0 goes left
    else if (a[mid] == 2) swap(a, mid, hi--);     // 2 goes right, recheck mid
    else mid++;                                   // 1 stays
  }
}
void swap(int[] a, int i, int j) { int t = a[i]; a[i] = a[j]; a[j] = t; }
// rotate right by k: reverse all, reverse first k, reverse the rest

Cost: O(n) time, O(1) extra space.

Classics: Sort Colors · Rotate Array · Product of Array Except Self

Three regions, three pointers; rotation = three reversals.

Searching & sorting 5 patterns

Binary search

If you see: "sorted", "find position / first / last", "O(log n)", "insert position"

Look at the middle, throw away the half that cannot hold the answer, repeat until one spot is left.

int lowerBound(int[] a, int target) {             // first i with a[i] >= target
  int lo = 0, hi = a.length;                      // answer lies in [lo, hi]
  while (lo < hi) {
    int mid = lo + (hi - lo) / 2;                 // no overflow
    if (a[mid] < target) lo = mid + 1;            // answer is right of mid
    else hi = mid;                                // mid might be it
  }
  return lo;
}

Cost: O(log n) time, O(1) space.

Classics: Binary Search · Search Insert Position · Find First and Last Position

lo < hi, hi = mid, lo = mid + 1: the one loop that never goes infinite.

Binary search on the answer

If you see: "minimum speed / capacity / time such that…", "maximise the minimum", "within D days"

If "can I do it with value X?" is a yes/no that flips only once as X grows, binary search X and run the check each time.

int minEatingSpeed(int[] piles, int h) {
  int lo = 1, hi = 1_000_000_000;
  while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    long hours = 0;
    for (int p : piles) hours += (p - 1) / mid + 1;   // ceil(p / mid)
    if (hours <= h) hi = mid;                         // fast enough: try slower
    else lo = mid + 1;
  }
  return lo;
}

Cost: O(n · log(range)) time, O(1) space.

Classics: Koko Eating Bananas · Capacity To Ship Packages Within D Days · Split Array Largest Sum

Guess the answer, check it, halve the guesses.

Rotated sorted array

If you see: "sorted then rotated", "pivot unknown", "find minimum", still O(log n)

Cut at the middle: one half is always properly sorted, so check if the target sits inside that half and drop the other.

int search(int[] a, int t) {
  int lo = 0, hi = a.length - 1;
  while (lo <= hi) {
    int mid = (lo + hi) >>> 1; if (a[mid] == t) return mid;
    if (a[lo] <= a[mid]) {                         // left half sorted
      if (a[lo] <= t && t < a[mid]) hi = mid - 1; else lo = mid + 1;
    } else {                                       // right half sorted
      if (a[mid] < t && t <= a[hi]) lo = mid + 1; else hi = mid - 1;
    }
  }
  return -1;
}

Cost: O(log n) time, O(1) space.

Classics: Search in Rotated Sorted Array · Find Minimum in Rotated Sorted Array · Search in Rotated Sorted Array II

One half is always sorted — ask that half.

Merge sort

If you see: "sort a linked list", "stable sort", "count inversions / smaller after self", "divide and conquer"

Split in half, sort each half the same way, then merge two sorted halves with two pointers — counting things during the merge is the interview twist.

void sort(int[] a, int lo, int hi, int[] tmp) {   // sorts a[lo..hi]
  if (lo >= hi) return;
  int mid = (lo + hi) >>> 1;
  sort(a, lo, mid, tmp);
  sort(a, mid + 1, hi, tmp);
  int i = lo, j = mid + 1, k = lo;
  while (i <= mid || j <= hi)
    tmp[k++] = (j > hi || (i <= mid && a[i] <= a[j])) ? a[i++] : a[j++];
  for (k = lo; k <= hi; k++) a[k] = tmp[k];
}

Cost: O(n log n) time always, O(n) extra space.

Classics: Sort an Array · Sort List · Count of Smaller Numbers After Self

Split, trust, merge.

Quick sort & quickselect

If you see: "kth largest / smallest", "partition around", "average O(n)"

Partition around a pivot so smaller values go left; the pivot lands in its final spot, so for kth element recurse into one side only.

int findKthLargest(int[] a, int k) {              // swap() as in Sort Colors
  int target = a.length - k, lo = 0, hi = a.length - 1;
  while (true) {
    swap(a, hi, lo + (int) (Math.random() * (hi - lo + 1))); // random pivot
    int pivot = a[hi], p = lo;
    for (int i = lo; i < hi; i++)
      if (a[i] < pivot) swap(a, i, p++);          // smaller ones to the left
    swap(a, p, hi);                               // pivot in its final place
    if (p == target) return a[p];
    if (p < target) lo = p + 1; else hi = p - 1;
  }
}

Cost: Quickselect O(n) average, O(n²) worst; quicksort O(n log n) average.

Classics: Kth Largest Element in an Array · K Closest Points to Origin · Sort an Array

Pivot lands home; keep only the side with k.

Linked lists 4 patterns

Reverse a linked list

If you see: "reverse", "reverse between m and n", "in groups of k", "palindrome list"

Walk the list once and turn each arrow around, keeping three pointers so you never lose the rest of the list.

ListNode reverse(ListNode head) {
  ListNode prev = null, curr = head;
  while (curr != null) {
    ListNode next = curr.next;                    // 1. save
    curr.next = prev;                             // 2. flip
    prev = curr;                                  // 3. step
    curr = next;
  }
  return prev;                                    // new head
}

Cost: O(n) time, O(1) space.

Classics: Reverse Linked List · Reverse Linked List II · Reverse Nodes in k-Group

Save, flip, step.

Fast & slow pointers

If you see: "cycle", "middle of the list", "nth from the end", "duplicate number in 1..n"

Move one pointer twice as fast as the other: if there is a loop they meet; if not, the slow one stops at the middle.

boolean hasCycle(ListNode head) {
  ListNode slow = head, fast = head;
  while (fast != null && fast.next != null) {
    slow = slow.next;                             // 1 step
    fast = fast.next.next;                        // 2 steps
    if (slow == fast) return true;                // they met in the loop
  }
  return false;                                   // no loop; slow = middle
}
// cycle start: after meeting, move one pointer to head, step both by 1

Cost: O(n) time, O(1) space.

Classics: Middle of the Linked List · Linked List Cycle II · Find the Duplicate Number

Hare and tortoise: a loop makes them meet.

Merge lists

If you see: "merge two / k sorted lists", "combine sorted streams", "add two numbers as lists"

Start with a dummy node and always attach the smaller head; for k lists, a min-heap tells you the smallest head.

ListNode merge(ListNode a, ListNode b) {
  ListNode dummy = new ListNode(0), tail = dummy;
  while (a != null && b != null) {
    if (a.val <= b.val) { tail.next = a; a = a.next; }
    else { tail.next = b; b = b.next; }
    tail = tail.next;
  }
  tail.next = (a != null) ? a : b;                // attach the leftover
  return dummy.next;
}

Cost: Two lists O(n + m); k lists with a heap O(N log k).

Classics: Merge Two Sorted Lists · Merge k Sorted Lists · Add Two Numbers

Dummy head first, then never special-case the start.

LRU cache

If you see: "least recently used", "evict", "get and put in O(1)", "capacity"

A HashMap finds the node in O(1) and a doubly linked list keeps use-order; in the interview write the list yourself — this is the shortcut to check your answer.

class LRUCache extends LinkedHashMap<Integer, Integer> {
  private final int cap;
  LRUCache(int capacity) {
    super(capacity, 0.75f, true);                 // true = access order
    cap = capacity;
  }
  public int get(int key) { return getOrDefault(key, -1); }
  public void put(int key, int value) { super.put(key, value); }
  @Override protected boolean removeEldestEntry(Map.Entry<Integer, Integer> e) {
    return size() > cap;                          // evict least recent
  }
}

Cost: O(1) per get / put, O(capacity) space.

Classics: LRU Cache · LFU Cache · Design Browser History

Map for "where", list for "when".

Stacks, queues & heaps 5 patterns

Stacks & queues

If you see: "valid brackets", "undo", "most recent first", "evaluate expression", "min stack"

A stack remembers the most recent unfinished thing; push when something opens, pop when it closes.

boolean isValid(String s) {
  Deque<Character> st = new ArrayDeque<>();
  for (char c : s.toCharArray()) {
    if (c == '(') st.push(')');                   // push the closer we expect
    else if (c == '[') st.push(']');
    else if (c == '{') st.push('}');
    else if (st.isEmpty() || st.pop() != c) return false;
  }
  return st.isEmpty();
}

Cost: O(n) time, O(n) space.

Classics: Valid Parentheses · Min Stack · Evaluate Reverse Polish Notation

Last opened, first closed.

Monotonic stack

If you see: "next greater / smaller element", "days until warmer", "largest rectangle", "stock span"

Keep a stack of indices whose values only go down; a bigger new value pops them and is their "next greater" answer.

int[] dailyTemperatures(int[] t) {
  int[] ans = new int[t.length];
  Deque<Integer> st = new ArrayDeque<>();         // indices, temps decreasing
  for (int i = 0; i < t.length; i++) {
    while (!st.isEmpty() && t[st.peek()] < t[i]) {
      int j = st.pop();
      ans[j] = i - j;                             // i is j's next warmer day
    }
    st.push(i);
  }
  return ans;
}

Cost: O(n) time — each index is pushed and popped once. O(n) space.

Classics: Daily Temperatures · Next Greater Element II · Largest Rectangle in Histogram

Waiting line of the unanswered; a taller one answers them all.

Heap (priority queue)

If you see: "smallest / largest so far", "repeatedly take the min", "schedule by priority", "merge k"

A heap always hands you the smallest (or largest) item in O(log n), even while items keep arriving.

PriorityQueue<Integer> minHeap = new PriorityQueue<>();
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
PriorityQueue<int[]> byFirst =
    new PriorityQueue<>((a, b) -> Integer.compare(a[0], b[0]));
minHeap.offer(5);                                 // O(log n) add
minHeap.offer(2);
int smallest = minHeap.peek();                    // O(1) look: 2
minHeap.poll();                                   // O(log n) remove the top

Cost: offer / poll O(log n), peek O(1), build from n items O(n).

Classics: Last Stone Weight · Kth Largest Element in a Stream · Task Scheduler

Compare with Integer.compare, never a − b.

Top K

If you see: "k most frequent", "k closest", "k largest", "k smallest"

Keep a heap of only k items, holding the opposite order: a min-heap for the k largest, so the weakest of the top k sits on top and is easy to drop.

int[] topKFrequent(int[] nums, int k) {
  Map<Integer, Integer> freq = new HashMap<>();
  for (int x : nums) freq.merge(x, 1, Integer::sum);
  PriorityQueue<Integer> heap =                   // min-heap by count
      new PriorityQueue<>((a, b) -> Integer.compare(freq.get(a), freq.get(b)));
  for (int x : freq.keySet()) {
    heap.offer(x);
    if (heap.size() > k) heap.poll();             // drop the least frequent
  }
  return heap.stream().mapToInt(Integer::intValue).toArray();
}

Cost: O(n log k) time, O(n) space.

Classics: Top K Frequent Elements · Top K Frequent Words · Find K Pairs with Smallest Sums

K largest → min-heap of size k (opposite heap).

Two heaps

If you see: "running median", "median of a stream", "balance two halves"

Keep the smaller half in a max-heap and the larger half in a min-heap; the median is at the tops.

class MedianFinder {
  PriorityQueue<Integer> lo = new PriorityQueue<>(Collections.reverseOrder());
  PriorityQueue<Integer> hi = new PriorityQueue<>();
  public void addNum(int x) {
    lo.offer(x);
    hi.offer(lo.poll());                          // biggest small one goes up
    if (hi.size() > lo.size()) lo.offer(hi.poll()); // keep lo the same or +1
  }
  public double findMedian() {
    return lo.size() > hi.size() ? lo.peek() : (lo.peek() + (long) hi.peek()) / 2.0;
  }
}

Cost: addNum O(log n), findMedian O(1).

Classics: Find Median from Data Stream · Sliding Window Median · IPO

Small half max-heap, big half min-heap, median at the seam.

Trees 7 patterns

Recursion

If you see: "defined in terms of itself", "nested", "tree / list structure", "divide in half"

Solve the smallest case directly, then trust the same function to solve a smaller piece and build your answer from it.

double power(double x, long n) {                  // x^n with n >= 0
  if (n == 0) return 1;                           // 1. base case
  double half = power(x, n / 2);                  // 2. trust the smaller call
  return n % 2 == 0 ? half * half                 // 3. combine
                    : half * half * x;
}

Cost: Time = number of calls × work per call. Space = depth of calls.

Classics: Pow(x, n) · Fibonacci Number · Swap Nodes in Pairs

Base case, smaller call, combine — and trust it.

Tree traversals

If you see: "inorder / preorder / postorder", "sorted order of a BST", "serialize", "build from traversals"

Visit left subtree, node and right subtree in a fixed order; where you write down the node gives pre, in or post order.

void inorder(TreeNode n, List<Integer> out) { if (n == null) return;
  inorder(n.left, out);                           // pre-order: add before this
  out.add(n.val);
  inorder(n.right, out);                          // post-order: add after this
}
List<Integer> inorderIter(TreeNode cur) {         // same, with a stack
  List<Integer> out = new ArrayList<>(); Deque<TreeNode> st = new ArrayDeque<>();
  while (cur != null || !st.isEmpty()) {
    while (cur != null) { st.push(cur); cur = cur.left; }
    cur = st.pop(); out.add(cur.val); cur = cur.right;
  }
  return out; }

Cost: O(n) time, O(h) space where h is the height.

Classics: Binary Tree Inorder Traversal · Binary Tree Preorder Traversal · Construct Binary Tree from Preorder and Inorder

Pre = me first, in = me middle, post = me last.

Level order (tree BFS)

If you see: "level by level", "right side view", "zigzag", "minimum depth", "per level average"

Use a queue; at the start of each round, its size is exactly the number of nodes on this level.

List<List<Integer>> levelOrder(TreeNode root) {
  List<List<Integer>> res = new ArrayList<>(); Deque<TreeNode> q = new ArrayDeque<>();
  if (root != null) q.offer(root);
  while (!q.isEmpty()) {
    List<Integer> level = new ArrayList<>();
    for (int i = q.size(); i > 0; i--) {          // exactly one level
      TreeNode n = q.poll(); level.add(n.val);
      if (n.left != null) q.offer(n.left); if (n.right != null) q.offer(n.right);
    }
    res.add(level);
  }
  return res; }

Cost: O(n) time, O(width) space.

Classics: Binary Tree Level Order Traversal · Binary Tree Right Side View · Binary Tree Zigzag Level Order Traversal

Freeze q.size() — that is one level.

Tree recursion

If you see: "depth", "diameter", "balanced", "path sum", "any question about a whole tree"

Ask three things: what do I return for null, what do I need from each child, and what do I give my parent (updating a global best on the way).

int best = 0;
int diameterOfBinaryTree(TreeNode root) { height(root); return best; }
int height(TreeNode n) {
  if (n == null) return 0;                        // 1. empty tree
  int l = height(n.left), r = height(n.right);    // 2. ask the children
  best = Math.max(best, l + r);                   // 3. best path through me
  return 1 + Math.max(l, r);                      //    my height, for my parent
}

Cost: O(n) time, O(h) space.

Classics: Maximum Depth of Binary Tree · Diameter of Binary Tree · Binary Tree Maximum Path Sum

Return one thing to the parent, record the other globally.

Binary search tree

If you see: "BST", "sorted tree", "kth smallest", "validate", "insert / delete"

Left is smaller, right is bigger at every node, so pass down a (low, high) range or walk left/right like binary search.

boolean isValidBST(TreeNode root) {
  return valid(root, Long.MIN_VALUE, Long.MAX_VALUE);
}
boolean valid(TreeNode n, long lo, long hi) {     // n.val must be in (lo, hi)
  if (n == null) return true;
  if (n.val <= lo || n.val >= hi) return false;
  return valid(n.left, lo, n.val) && valid(n.right, n.val, hi);
}
TreeNode search(TreeNode n, int x) {
  while (n != null && n.val != x) n = x < n.val ? n.left : n.right;
  return n;
}

Cost: Search / insert O(h); validate O(n). h = log n if balanced, n if not.

Classics: Validate Binary Search Tree · Kth Smallest Element in a BST · Delete Node in a BST

Pass the range down, not just the parent.

Lowest common ancestor

If you see: "common ancestor", "where two paths meet", "distance between two nodes"

Search both sides: if p and q are found on different sides, this node is where their paths split.

TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
  if (root == null || root == p || root == q) return root;
  TreeNode l = lowestCommonAncestor(root.left, p, q);
  TreeNode r = lowestCommonAncestor(root.right, p, q);
  if (l != null && r != null) return root;        // split here
  return l != null ? l : r;                       // pass up what was found
}
// BST: go left while both < root, right while both > root, else root

Cost: O(n) time, O(h) space; in a BST O(h).

Classics: LCA of a Binary Tree · LCA of a Binary Search Tree · LCA of Deepest Leaves

Found on both sides → I am the answer.

Trie (prefix tree)

If you see: "prefix", "starts with", "autocomplete", "dictionary of words", "word search with many words"

Store words letter by letter in a tree of 26-way nodes, so checking any prefix costs only its length.

class Trie {
  Trie[] next = new Trie[26];
  boolean end;                                    // a word ends here
  void insert(String w) {
    Trie t = this;
    for (char c : w.toCharArray()) {
      if (t.next[c - 'a'] == null) t.next[c - 'a'] = new Trie();
      t = t.next[c - 'a'];
    }
    t.end = true;
  }
} // search / startsWith: walk the same way; word needs end, prefix needs a node

Cost: O(L) per insert / lookup; space up to total letters × 26.

Classics: Implement Trie (Prefix Tree) · Design Add and Search Words Data Structure · Word Search II

One letter per level; mark where words end.

Graphs 7 patterns

Graph basics

If you see: "connected", "network", "friends of friends", "nodes and edges", "is there a path"

Turn the edge list into an adjacency list, then DFS or BFS from each unvisited node, marking visited so you never loop.

List<List<Integer>> g = new ArrayList<>();
boolean[] seen;
int countComponents(int n, int[][] edges) {
  for (int i = 0; i < n; i++) g.add(new ArrayList<>());
  for (int[] e : edges) { g.get(e[0]).add(e[1]); g.get(e[1]).add(e[0]); }
  seen = new boolean[n]; int count = 0;
  for (int u = 0; u < n; u++) if (!seen[u]) { count++; dfs(u); }
  return count;
}
void dfs(int u) {
  seen[u] = true;
  for (int v : g.get(u)) if (!seen[v]) dfs(v); }

Cost: O(V + E) time and space.

Classics: Find if Path Exists in Graph · Number of Provinces · Clone Graph

Adjacency list + visited set — every graph starts here.

Grids (BFS / DFS)

If you see: "islands", "flood fill", "connected cells", "shortest path in a maze", "4 directions"

Each cell is a node with up to 4 neighbours; DFS to explore a region, BFS when you need the fewest steps.

int numIslands(char[][] g) {
  int count = 0;
  for (int r = 0; r < g.length; r++)
    for (int c = 0; c < g[0].length; c++)
      if (g[r][c] == '1') { count++; sink(g, r, c); }
  return count;
}
void sink(char[][] g, int r, int c) {
  if (r < 0 || c < 0 || r >= g.length || c >= g[0].length || g[r][c] != '1') return;
  g[r][c] = '0';                                  // mark visited
  sink(g, r + 1, c); sink(g, r - 1, c); sink(g, r, c + 1); sink(g, r, c - 1);
}

Cost: O(R × C) time, O(R × C) worst-case stack.

Classics: Number of Islands · Max Area of Island · Shortest Path in Binary Matrix

Bounds check first, then mark, then 4 calls.

Multi-source BFS

If you see: "nearest X for every cell", "spreads every minute", "rotting", "distance to closest"

Put every starting cell in the queue at once; the BFS wave then gives each cell its distance to the nearest start.

int[][] updateMatrix(int[][] mat) {               // distance to nearest 0
  int R = mat.length, C = mat[0].length; int[][] dist = new int[R][C];
  Deque<int[]> q = new ArrayDeque<>();
  for (int r = 0; r < R; r++) for (int c = 0; c < C; c++)
    if (mat[r][c] == 0) q.offer(new int[]{r, c}); else dist[r][c] = -1;
  while (!q.isEmpty()) { int[] p = q.poll();
    for (int[] d : new int[][]{{1, 0}, {-1, 0}, {0, 1}, {0, -1}}) {
      int r = p[0] + d[0], c = p[1] + d[1];
      if (r < 0 || c < 0 || r >= R || c >= C || dist[r][c] != -1) continue;
      dist[r][c] = dist[p[0]][p[1]] + 1; q.offer(new int[]{r, c}); } }
  return dist;
}

Cost: O(R × C) time and space.

Classics: Rotting Oranges · 01 Matrix · Pacific Atlantic Water Flow

All sources go in the queue before the first step.

Topological sort

If you see: "prerequisites", "dependencies", "build order", "can all tasks finish", "ordering of letters"

Count incoming arrows; repeatedly take a node with zero, and "remove" its arrows. If some nodes never reach zero, there is a cycle.

int[] findOrder(int n, int[][] pre) {             // pre[i] = {course, needs}
  List<List<Integer>> g = new ArrayList<>(); int[] indeg = new int[n];
  for (int i = 0; i < n; i++) g.add(new ArrayList<>());
  for (int[] p : pre) { g.get(p[1]).add(p[0]); indeg[p[0]]++; }
  Deque<Integer> q = new ArrayDeque<>();
  for (int i = 0; i < n; i++) if (indeg[i] == 0) q.offer(i);
  int[] order = new int[n]; int k = 0;
  while (!q.isEmpty()) { int u = q.poll(); order[k++] = u;
    for (int v : g.get(u)) if (--indeg[v] == 0) q.offer(v); }
  return k == n ? order : new int[0];             // k < n means a cycle
}

Cost: O(V + E) time and space.

Classics: Course Schedule · Course Schedule II · Find All Possible Recipes from Given Supplies

Zero in-degree goes first; leftovers mean a cycle.

Union-find

If you see: "connected groups", "merge accounts", "redundant edge", "are a and b connected", edges arrive one by one

Each group has a leader; find follows parents to the leader (squashing the path), union joins two leaders.

int[] parent, rank;
void init(int n) {
  parent = new int[n]; rank = new int[n];
  for (int i = 0; i < n; i++) parent[i] = i;
}
int find(int x) { return parent[x] == x ? x : (parent[x] = find(parent[x])); }
boolean union(int a, int b) {
  int ra = find(a), rb = find(b);
  if (ra == rb) return false;                     // already connected
  if (rank[ra] < rank[rb]) { int t = ra; ra = rb; rb = t; }
  parent[rb] = ra; if (rank[ra] == rank[rb]) rank[ra]++;
  return true; }

Cost: Almost O(1) per operation (inverse Ackermann), O(n) space.

Classics: Redundant Connection · Number of Provinces · Accounts Merge

Find the boss, squash the path, join the bosses.

Dijkstra

If you see: "shortest / cheapest path", "weighted edges", "network delay", "minimum time", weights ≥ 0

Always settle the closest unsettled node next (min-heap by distance) and relax its edges; skip stale heap entries.

int[] dijkstra(List<List<int[]>> g, int src) {    // g.get(u) holds {v, w}
  int[] dist = new int[g.size()]; Arrays.fill(dist, Integer.MAX_VALUE);
  PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> Integer.compare(a[1], b[1]));
  dist[src] = 0; pq.offer(new int[]{src, 0});
  while (!pq.isEmpty()) { int[] top = pq.poll(); int u = top[0];
    if (top[1] > dist[u]) continue;               // stale entry, skip
    for (int[] e : g.get(u)) { int nd = dist[u] + e[1];
      if (nd < dist[e[0]]) { dist[e[0]] = nd; pq.offer(new int[]{e[0], nd}); } }
  }
  return dist;
}

Cost: O((V + E) log V) time, O(V + E) space.

Classics: Network Delay Time · Path With Minimum Effort · Swim in Rising Water

BFS with a heap; no negative weights.

Minimum spanning tree

If you see: "connect all points / cities at minimum cost", "cheapest network", "no cycles, everyone connected"

Kruskal: sort edges by cost and take each one that joins two different groups (union-find), until n − 1 edges are taken.

int kruskal(int n, int[][] edges) {               // edges[i] = {u, v, w}
  Arrays.sort(edges, (a, b) -> Integer.compare(a[2], b[2]));
  init(n);                                        // union-find from its card
  int cost = 0, used = 0;
  for (int[] e : edges)
    if (union(e[0], e[1])) { cost += e[2]; if (++used == n - 1) break; }
  return used == n - 1 ? cost : -1;               // -1: not connected
}

Cost: Kruskal O(E log E); Prim with a heap O(E log V).

Classics: Min Cost to Connect All Points · Find Critical and Pseudo-Critical Edges in MST · Path With Minimum Effort

Cheapest edge that does not close a loop.

Backtracking 3 patterns

Backtracking

If you see: "all subsets / combinations", "every way to", "generate all", "word search", n ≤ 20

Build the answer one choice at a time: choose, explore deeper, then undo the choice and try the next one.

List<List<Integer>> subsets(int[] nums) {
  List<List<Integer>> res = new ArrayList<>(); build(nums, 0, new ArrayList<>(), res);
  return res;
}
void build(int[] nums, int start, List<Integer> cur, List<List<Integer>> res) {
  res.add(new ArrayList<>(cur));                  // every node is a subset
  for (int i = start; i < nums.length; i++) {
    cur.add(nums[i]);                             // choose
    build(nums, i + 1, cur, res);                 // explore
    cur.remove(cur.size() - 1);                   // un-choose
  }
}

Cost: O(2^n · n) time for subsets, O(n) recursion depth.

Classics: Subsets · Combination Sum · Word Search

Choose, explore, un-choose — copy the list when you save it.

Permutations

If you see: "all orderings", "arrangements", "with duplicates", "letter combinations"

Each level picks one unused item; a used[] array tracks what is taken, and sorting lets you skip duplicate picks.

void permute(int[] nums, boolean[] used, List<Integer> cur, List<List<Integer>> res) {
  if (cur.size() == nums.length) { res.add(new ArrayList<>(cur)); return; }
  for (int i = 0; i < nums.length; i++) {         // nums sorted for dup skip
    if (used[i]) continue;
    if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
    used[i] = true; cur.add(nums[i]);
    permute(nums, used, cur, res);
    used[i] = false; cur.remove(cur.size() - 1);
  }
}

Cost: O(n! · n) time, O(n) depth.

Classics: Permutations · Permutations II · Letter Combinations of a Phone Number

used[] for "taken", sorted + !used[i−1] for "same value, skip".

N-Queens

If you see: "place so none attack", "sudoku", "constraint puzzle", board fill

Place one queen per row; keep sets for columns and both diagonals so each safety check is O(1), and undo on the way back.

int n, count; boolean[] col, d1, d2;
int totalNQueens(int n) { this.n = n; col = new boolean[n];
  d1 = new boolean[2 * n]; d2 = new boolean[2 * n]; place(0); return count; }
void place(int r) {
  if (r == n) { count++; return; }
  for (int c = 0; c < n; c++) {
    if (col[c] || d1[r + c] || d2[r - c + n]) continue;  // attacked
    col[c] = d1[r + c] = d2[r - c + n] = true;           // place
    place(r + 1);
    col[c] = d1[r + c] = d2[r - c + n] = false;          // undo
  }
}

Cost: About O(n!) time, O(n) space.

Classics: N-Queens · N-Queens II · Sudoku Solver

r + c and r − c name the diagonals.

Dynamic programming 6 patterns

DP intro (1D)

If you see: "number of ways", "minimum / maximum", "can you reach", choices at each step, overlapping subproblems

Define dp[i] as the answer for the first i items, write how it depends on smaller i, and fill it from small to large.

int rob(int[] nums) {                             // House Robber
  int prev2 = 0, prev1 = 0;                       // best up to i-2, i-1
  for (int x : nums) {
    int cur = Math.max(prev1, prev2 + x);         // skip it, or rob it
    prev2 = prev1;
    prev1 = cur;
  }
  return prev1;
}

Cost: O(n) time, O(1) space after rolling variables.

Classics: Climbing Stairs · House Robber · Decode Ways

Recursion → memo → table → two variables.

Coin change

If you see: "fewest coins", "number of ways to make amount", "unlimited supply", "perfect squares"

dp[a] = best way to make amount a; try every coin as the last coin used.

int coinChange(int[] coins, int amount) {
  int[] dp = new int[amount + 1];                 // dp[a] = fewest coins for a
  Arrays.fill(dp, amount + 1); dp[0] = 0;         // amount+1 means impossible
  for (int a = 1; a <= amount; a++)
    for (int c : coins)
      if (c <= a) dp[a] = Math.min(dp[a], dp[a - c] + 1);
  return dp[amount] > amount ? -1 : dp[amount];
}
// number of ways: coins in the OUTER loop, amounts inner, dp[a] += dp[a - c]

Cost: O(amount × coins) time, O(amount) space.

Classics: Coin Change · Coin Change II · Perfect Squares

Last coin is c → dp[a − c] + 1.

Longest increasing subsequence

If you see: "longest increasing subsequence", "chain", "nested envelopes", "not necessarily contiguous"

Keep tails[len] = smallest possible ending of an increasing run of that length; binary search where each number goes.

int lengthOfLIS(int[] nums) {
  int[] tails = new int[nums.length]; int len = 0;
  for (int x : nums) {
    int lo = 0, hi = len;                         // first tail >= x
    while (lo < hi) {
      int mid = (lo + hi) >>> 1;
      if (tails[mid] < x) lo = mid + 1; else hi = mid;
    }
    tails[lo] = x; if (lo == len) len++;          // replace or extend
  }
  return len;
}

Cost: O(n log n) with tails; the simple dp[i] version is O(n²).

Classics: Longest Increasing Subsequence · Number of Longest Increasing Subsequence · Russian Doll Envelopes

Smallest tail per length; binary search the slot.

LCS & edit distance

If you see: "two strings", "common subsequence", "minimum edits / operations", "transform one into the other"

Fill a table where dp[i][j] compares the first i letters of one string with the first j of the other; each cell looks up, left and diagonal.

int minDistance(String a, String b) {
  int m = a.length(), n = b.length();
  int[][] dp = new int[m + 1][n + 1];             // first i of a vs first j of b
  for (int i = 0; i <= m; i++) dp[i][0] = i;
  for (int j = 0; j <= n; j++) dp[0][j] = j;
  for (int i = 1; i <= m; i++)
    for (int j = 1; j <= n; j++)
      dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1) ? dp[i - 1][j - 1]
          : 1 + Math.min(dp[i - 1][j - 1], Math.min(dp[i - 1][j], dp[i][j - 1]));
  return dp[m][n];
}
// LCS: borders 0; match → diagonal + 1, else max(up, left)

Cost: O(m × n) time, O(m × n) space (O(n) with two rows).

Classics: Longest Common Subsequence · Edit Distance · Delete Operation for Two Strings

Two strings → 2D table, diagonal means "use both letters".

Knapsack (0/1)

If you see: "pick a subset with sum / weight limit", "partition into equal halves", "target sum with + and −", each item once

dp[s] = can I make total s; for each item, update s from high to low so the item is used at most once.

boolean canPartition(int[] nums) {
  int sum = 0;
  for (int x : nums) sum += x;
  if (sum % 2 == 1) return false;
  boolean[] dp = new boolean[sum / 2 + 1];        // dp[s]: some items make s
  dp[0] = true;
  for (int x : nums)
    for (int s = sum / 2; s >= x; s--)            // backwards: each item once
      dp[s] = dp[s] || dp[s - x];
  return dp[sum / 2];
}

Cost: O(n × target) time, O(target) space.

Classics: Partition Equal Subset Sum · Target Sum · Last Stone Weight II

Take it or leave it; loop capacity backwards.

Grid DP

If you see: "paths from top-left to bottom-right", "only right or down", "minimum path sum", "largest square"

Each cell's answer comes from the cell above and the cell to the left, so fill row by row.

int uniquePaths(int m, int n) {
  int[] dp = new int[n];
  Arrays.fill(dp, 1);                             // first row: one way each
  for (int r = 1; r < m; r++)
    for (int c = 1; c < n; c++)
      dp[c] += dp[c - 1];                         // from above + from left
  return dp[n - 1];
}

Cost: O(m × n) time, O(n) space with one row.

Classics: Unique Paths · Minimum Path Sum · Maximal Square

Above + left; one row is enough.

Greedy, intervals & bits 3 patterns

Intervals

If you see: "meetings", "overlapping ranges", "merge", "insert interval", "minimum rooms", "remove fewest to stop overlap"

Sort by start; then each interval either overlaps the last kept one (merge by extending its end) or starts a new one.

int[][] merge(int[][] iv) {
  Arrays.sort(iv, (a, b) -> Integer.compare(a[0], b[0]));
  List<int[]> out = new ArrayList<>();
  for (int[] cur : iv) {
    int[] last = out.isEmpty() ? null : out.get(out.size() - 1);
    if (last == null || last[1] < cur[0]) out.add(cur);   // no overlap
    else last[1] = Math.max(last[1], cur[1]);             // extend
  }
  return out.toArray(new int[0][]);
}
// min rooms: sort by start, min-heap of end times, pop ends <= start

Cost: O(n log n) for the sort, O(n) space.

Classics: Merge Intervals · Insert Interval · Non-overlapping Intervals

Sort by start, compare with the last kept end.

Greedy

If you see: "minimum number of jumps / arrows / coins (canonical)", "can you reach", "earliest finish", one pass with a running best

Make the locally best choice when you can argue it never hurts later — e.g. keep the farthest index you can reach.

boolean canJump(int[] nums) {
  int reach = 0;                                  // farthest index reachable
  for (int i = 0; i < nums.length; i++) {
    if (i > reach) return false;                  // stuck before i
    reach = Math.max(reach, i + nums[i]);
  }
  return true;
}

Cost: Usually O(n) or O(n log n) with a sort, O(1) space.

Classics: Jump Game · Jump Game II · Gas Station

Greedy needs a reason: say why the local choice is safe.

Bit tricks

If you see: "appears twice except one", "without extra space", "power of two", "count 1 bits", "subsets as masks"

XOR cancels pairs (a ^ a = 0), n & (n − 1) removes the lowest 1-bit, and 1 << i reaches bit i.

int singleNumber(int[] nums) {                    // pairs cancel out
  int x = 0;
  for (int v : nums) x ^= v;
  return x;
}
int hammingWeight(int n) {                        // count 1 bits
  int c = 0;
  while (n != 0) { n &= n - 1; c++; }             // drop the lowest 1
  return c;
}
boolean isPowerOfTwo(int n) { return n > 0 && (n & (n - 1)) == 0; }
boolean hasBit(int n, int i) { return ((n >> i) & 1) == 1; }

Cost: O(1) per trick, O(number of 1 bits) for counting.

Classics: Single Number · Number of 1 Bits · Counting Bits

XOR cancels, n & (n−1) drops one.

MAANG extras 8 patterns

Strings & palindromes

If you see: "palindrome", "longest palindromic substring", "count palindromes", "reads the same backwards"

Every palindrome has a centre; grow outward from each of the 2n − 1 centres while both ends match.

String longestPalindrome(String s) {
  int start = 0, len = 0;
  for (int c = 0; c < s.length(); c++)
    for (int gap = 0; gap < 2; gap++) {           // 0: centre c, 1: between c, c+1
      int l = c, r = c + gap;
      while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
      if (r - l - 1 > len) { len = r - l - 1; start = l + 1; }
    }
  return s.substring(start, start + len);
}

Cost: O(n²) time, O(1) space.

Classics: Longest Palindromic Substring · Palindromic Substrings · Valid Palindrome II

2n − 1 centres, expand while equal.

Matrix traversal

If you see: "spiral order", "rotate the image", "diagonal", "in place on a matrix", "set rows and columns"

Track four borders (top, bottom, left, right) and shrink one after walking it; rotate = transpose then reverse each row.

List<Integer> spiralOrder(int[][] m) {
  List<Integer> out = new ArrayList<>();
  int top = 0, bot = m.length - 1, left = 0, right = m[0].length - 1;
  while (top <= bot && left <= right) {
    for (int c = left; c <= right; c++) out.add(m[top][c]);
    for (int r = ++top; r <= bot; r++) out.add(m[r][right]);
    right--;
    if (top <= bot) { for (int c = right; c >= left; c--) out.add(m[bot][c]); bot--; }
    if (left <= right) { for (int r = bot; r >= top; r--) out.add(m[r][left]); left++; }
  }
  return out;
}

Cost: O(m × n) time, O(1) extra space.

Classics: Spiral Matrix · Rotate Image · Set Matrix Zeroes

Walk a border, shrink it, check before the return trip.

Monotonic deque

If you see: "maximum / minimum of every window of size k", "sliding window max", "best in the last k"

Keep indices in a deque with values decreasing; drop from the front when it leaves the window, from the back when a bigger value arrives.

int[] maxSlidingWindow(int[] a, int k) {
  int[] res = new int[a.length - k + 1];
  Deque<Integer> dq = new ArrayDeque<>();         // indices, values decreasing
  for (int i = 0; i < a.length; i++) {
    if (!dq.isEmpty() && dq.peekFirst() <= i - k) dq.pollFirst();    // left window
    while (!dq.isEmpty() && a[dq.peekLast()] <= a[i]) dq.pollLast(); // useless now
    dq.offerLast(i);
    if (i >= k - 1) res[i - k + 1] = a[dq.peekFirst()];             // front = max
  }
  return res;
}

Cost: O(n) time, O(k) space.

Classics: Sliding Window Maximum · Shortest Subarray with Sum at Least K · Constrained Subsequence Sum

Front is the max; back throws out the hopeless.

Shortest paths, advanced

If you see: "at most K stops / edges", "negative weights", "weights 0 or 1", "all pairs", small n

Bellman-Ford relaxes every edge once per allowed hop (copy the array each round for "at most K"); 0-1 BFS uses a deque; Floyd-Warshall does all pairs.

int findCheapestPrice(int n, int[][] flights, int src, int dst, int k) {
  int INF = Integer.MAX_VALUE; int[] dist = new int[n];
  Arrays.fill(dist, INF); dist[src] = 0;
  for (int i = 0; i <= k; i++) {                  // k stops = k + 1 flights
    int[] next = dist.clone();                    // use last round only
    for (int[] f : flights)                       // f = {from, to, price}
      if (dist[f[0]] != INF && dist[f[0]] + f[2] < next[f[1]])
        next[f[1]] = dist[f[0]] + f[2];
    dist = next;
  }
  return dist[dst] == INF ? -1 : dist[dst];
}

Cost: Bellman-Ford O(K × E); 0-1 BFS O(V + E); Floyd-Warshall O(V³).

Classics: Cheapest Flights Within K Stops · Minimum Cost to Make at Least One Valid Path in a Grid · Find the City With the Smallest Number of Neighbors

Limit on edges → Bellman-Ford with a copy per round.

Segment tree & Fenwick

If you see: "update a value AND query range sums, many times", "count smaller before me", "range min with updates"

A Fenwick tree stores partial sums at power-of-two jumps, so both point update and prefix sum walk only log n cells.

class Fenwick {                                   // indexes 1..n
  int[] t; Fenwick(int n) { t = new int[n + 1]; }
  void add(int i, int delta) {
    for (; i < t.length; i += i & -i) t[i] += delta;
  }
  int sum(int i) {                                // a[1] + ... + a[i]
    int s = 0;
    for (; i > 0; i -= i & -i) s += t[i];
    return s;
  }
  int range(int l, int r) { return sum(r) - sum(l - 1); }
}

Cost: O(log n) per update and query, O(n) space.

Classics: Range Sum Query - Mutable · Count of Smaller Numbers After Self · Create Sorted Array through Instructions

i & −i is the lowest bit: add climbs up, sum climbs down.

DP, advanced

If you see: "burst / merge / cut a range", "subset of n ≤ 20 items", "holding vs not holding", "cooldown"

When 1D/2D tables are not enough: interval DP (solve short ranges first), bitmask DP (a subset stored as an int), state-machine DP (one value per state).

int maxCoins(int[] nums) {                        // Burst Balloons
  int n = nums.length + 2; int[] a = new int[n];
  a[0] = a[n - 1] = 1; for (int i = 1; i < n - 1; i++) a[i] = nums[i - 1];
  int[][] dp = new int[n][n];                     // best for balloons in (l, r)
  for (int gap = 2; gap < n; gap++)               // short ranges first
    for (int l = 0; l + gap < n; l++) {
      int r = l + gap;
      for (int k = l + 1; k < r; k++)             // k = LAST balloon burst
        dp[l][r] = Math.max(dp[l][r], dp[l][k] + a[l] * a[k] * a[r] + dp[k][r]);
    }
  return dp[0][n - 1];
}

Cost: Interval DP O(n³); bitmask DP O(2^n × n); state machine O(n).

Classics: Burst Balloons · Best Time to Buy and Sell Stock with Cooldown · Partition to K Equal Sum Subsets

Range problems: pick what happens LAST.

Advanced graphs

If you see: "critical connection", "bridge", "two colours / two teams", "use every edge once", "strongly connected"

DFS with discovery time and "lowest reachable time" finds bridges; BFS 2-colouring checks bipartite; Hierholzer builds an Euler path.

int timer; int[] tin, low;                        // caller: new int[n] each
List<List<Integer>> bridges = new ArrayList<>();
void dfs(List<List<Integer>> g, int u, int parent) {   // start: dfs(g, 0, -1)
  tin[u] = low[u] = ++timer;
  for (int v : g.get(u)) {
    if (v == parent) continue;
    if (tin[v] == 0) {                            // tree edge
      dfs(g, v, u);
      low[u] = Math.min(low[u], low[v]);
      if (low[v] > tin[u]) bridges.add(List.of(u, v)); // v can't climb above u
    } else low[u] = Math.min(low[u], tin[v]);     // back edge
  } }

Cost: O(V + E) time and space.

Classics: Critical Connections in a Network · Is Graph Bipartite? · Reconstruct Itinerary

low[v] > tin[u] → the edge u–v is a bridge.

Design problems

If you see: "design a class that supports…", "in O(1)", "getRandom", "timestamp", "hit counter", "twitter feed"

List the operations and their required speed, then combine structures: map + array, map + linked list, map + heap, map + sorted map.

class RandomizedSet {
  List<Integer> vals = new ArrayList<>(); Map<Integer, Integer> pos = new HashMap<>();
  Random rnd = new Random();
  public boolean insert(int x) { if (pos.containsKey(x)) return false;
    pos.put(x, vals.size()); vals.add(x); return true; }
  public boolean remove(int x) {
    Integer i = pos.remove(x); if (i == null) return false;
    int last = vals.remove(vals.size() - 1);      // pop the last value
    if (i < vals.size()) { vals.set(i, last); pos.put(last, i); } // fill the hole
    return true; }
  public int getRandom() { return vals.get(rnd.nextInt(vals.size())); }
}

Cost: O(1) average per operation, O(n) space.

Pattern-spotting drill

60 problems in plain words, the way an interviewer tells them. Name the pattern before you open the answer.

Given a list of flights with prices, find the cheapest route from city A to city B with at most K stops.

Bellman-Ford with K + 1 rounds (or BFS by number of stops). A limit on the number of edges breaks plain Dijkstra; relaxing all edges once per allowed flight respects it. Lesson: Shortest paths, advanced

Given a set of distinct toppings, list every possible pizza (every subset).

Backtracking (subsets). "All subsets" → include or skip each item, 2^n results. Lesson: Backtracking

Return an array where each item is the product of all other items, without using division.

Prefix and suffix products (in place). Product of all left times product of all right. Lesson: In-place tricks, Prefix sum

List every distinct order in which a playlist with repeated songs can be played.

Permutations with duplicate skip. Sort, used[] array, skip a value equal to the previous unused one. Lesson: Permutations

Servers are connected by cables with travel times. How long until a signal from server k reaches every server?

Dijkstra. Shortest paths from one source with non-negative weights; answer is the largest distance. Lesson: Dijkstra

Find the largest sum of any path between any two nodes in a binary tree (values can be negative).

Tree recursion with a global best. Return the best one-sided path to the parent; update the answer with left + node + right. Lesson: Tree recursion

For each number in a list, count how many smaller numbers come after it.

Merge sort counting (or Fenwick tree). While merging, every right-side item placed before a left item is smaller and after it. Lesson: Merge sort, Segment tree & Fenwick

Each array cell says how far you may jump from it. Can you reach the last cell?

Greedy (farthest reach). Track the farthest reachable index in one pass. Lesson: Greedy

Courses have prerequisites. Return an order that takes them all, or say it is impossible.

Topological sort (Kahn's BFS). Dependencies form a directed graph; "impossible" means a cycle. Lesson: Topological sort

Given today's meetings, how many meeting rooms are needed at minimum?

Intervals + min-heap of end times. Sort by start; the heap tells you whether the earliest-ending room is free. Lesson: Intervals, Heap (priority queue)

An array of scores gets many updates, and many questions "what is the total from i to j?" mixed in.

Fenwick tree (or segment tree). Both updates and range sums in O(log n); a plain prefix sum would need O(n) per update. Lesson: Segment tree & Fenwick

Buy and sell a stock many times, but after a sale you must wait one day. Find the best profit.

State-machine DP. Three states per day — holding, just sold, resting — each from yesterday's states. Lesson: DP, advanced

Find the length of the longest stretch of a string with no repeated character.

Sliding window + hash map. Longest contiguous substring with a rule → grow right, shrink left when the rule breaks. Lesson: Sliding window

Check whether a string of brackets ( ) [ ] { } is properly nested.

Stack. Most recent opened must close first. Lesson: Stacks & queues

Reverse a linked list in blocks of k nodes, leaving a short final block as it is.

Linked list reversal (in groups). The prev/curr/next flip, applied k nodes at a time with a dummy head. Lesson: Reverse a linked list

A warehouse grid has walls and several robots. For every empty cell, find the distance to the nearest robot.

Multi-source BFS. Nearest of many starts → put all robots in the queue first. Lesson: Multi-source BFS

In a family tree, find the closest shared ancestor of two people.

Lowest common ancestor. Where the paths to the two nodes split. Lesson: Lowest common ancestor

Return the values of a company org chart (a tree) floor by floor, top to bottom.

Tree BFS (level order). Level by level → queue, one level per round. Lesson: Level order (tree BFS)

A sorted dictionary from an unknown alphabet is given. Work out the order of its letters.

Topological sort. Each adjacent word pair gives one "a before b" edge; order the letters. Lesson: Topological sort

Your solution is O(n²) and n can be 100,000. Will it pass, and what should you aim for?

Big-O budgeting. 10^10 steps is far over ~10^8 per second; aim for O(n log n) or O(n). Lesson: Big-O

A printer must finish jobs of different sizes in H hours. Find the slowest pages-per-hour speed that still finishes.

Binary search on the answer. "Minimum speed such that…" — check a speed in O(n), halve the range. Lesson: Binary search on the answer

From a list of version numbers over time, find the longest strictly increasing sequence (not necessarily consecutive).

Longest increasing subsequence. Subsequence + increasing → tails array with binary search. Lesson: Longest increasing subsequence

Design a cache with a fixed size that throws out the least recently used item. get and put must be O(1).

LRU cache: hash map + doubly linked list. Map finds the node in O(1); the list moves it to "most recent" in O(1). Lesson: LRU cache

Rebuild a binary tree given its preorder and inorder listings.

Tree traversals. Preorder's first value is the root; its place in inorder splits left from right. Lesson: Tree traversals

Vertical lines of different heights: pick two that, with the x-axis, hold the most water.

Two pointers from both ends. Moving the shorter line inward is the only move that might help. Lesson: Two pointers

Compute x to the power n for n up to 2 billion, faster than multiplying n times.

Recursion (fast power). x^n = (x^(n/2))² — halve n each call, O(log n). Lesson: Recursion

Merge k sorted log files into one sorted stream.

Merge lists + min-heap. The heap always gives the smallest current head out of k. Lesson: Merge lists, Heap (priority queue)

Each user account lists several emails. Merge accounts that share any email.

Union-find (or graph DFS). Grouping things that are connected through shared items. Lesson: Union-find

Design a set with insert, remove and getRandom, all in O(1) average.

Design: hash map + array. The array gives random access; the map gives positions so removal swaps with the last. Lesson: Design problems

Connect all office buildings with network cable using the least total length.

Minimum spanning tree (Kruskal / Prim). Connect everyone, no cycles, minimum total cost. Lesson: Minimum spanning tree

Versions 1..n were released; after some version all are broken. With isBad(v), find the first bad version in the fewest calls.

Binary search (lower bound). Good…good bad…bad is sorted; find the first true. Lesson: Binary search

For each day of stock prices, find how many days you wait until a higher price.

Monotonic stack. "Next greater element" for every position in O(n). Lesson: Monotonic stack

Count how many contiguous subarrays add up to exactly K. Numbers can be negative.

Prefix sum + hash map. Negatives break the sliding window; count earlier prefix sums equal to "now − K". Lesson: Prefix sum

Print the numbers of an m × n matrix in clockwise spiral order.

Matrix traversal with four borders. Walk a border, shrink it, repeat. Lesson: Matrix traversal

Find every cable in a data-centre network whose cut would split the network in two.

Bridges (Tarjan low-link). An edge u–v is a bridge when v's subtree cannot reach above u. Lesson: Advanced graphs

A vending machine must return change using the fewest coins from given denominations.

Coin change (unbounded DP). Fewest items with unlimited supply → dp over amounts. Greedy fails for some coin sets. Lesson: Coin change

What is the fewest single-letter inserts, deletes or replacements to turn one word into another?

Edit distance (2D DP). Two strings + minimum operations → table over prefixes of both. Lesson: LCS & edit distance

You can climb 1 or 2 steps at a time. In how many ways can you reach step n?

DP intro (Fibonacci-style). Ways(n) = ways(n − 1) + ways(n − 2): overlapping subproblems. Lesson: DP intro (1D)

Find all words from a dictionary that can be traced on a letter grid by moving to neighbours.

Trie + backtracking on the grid. The trie stops a DFS path as soon as no word has that prefix. Lesson: Trie (prefix tree), Backtracking

Find the kth largest number in an unsorted array, faster than sorting on average.

Quickselect (or a heap of size k). Partition puts the pivot in its final place; recurse into one side only. Lesson: Quick sort & quickselect, Top K

Return every way to cut a string into pieces that are all palindromes.

Backtracking (+ palindrome check). "Every way" → choose a cut, explore the rest, undo. Lesson: Backtracking, Strings & palindromes

Daily profit can be negative. Find the best total profit over any run of consecutive days.

Kadane. Maximum-sum contiguous subarray: extend or restart. Lesson: Kadane

An array of n + 1 numbers holds values 1..n. Find the repeated number without changing the array, in O(1) space.

Fast & slow pointers (Floyd). Treat value as "next index": the duplicate is the start of a cycle. Lesson: Fast & slow pointers

A satellite image is a grid of land and water. Count the separate pieces of land.

Grid DFS / BFS (islands). Connected regions in a grid → flood each one and count. Lesson: Grids (BFS / DFS)

Find the longest part of a DNA string that reads the same backwards.

Expand around centre. Longest palindromic substring → grow from each of 2n − 1 centres. Lesson: Strings & palindromes

Numbers arrive one at a time from a sensor. After each one, report the median so far.

Two heaps. Running median → max-heap for the low half, min-heap for the high half. Lesson: Two heaps

A sorted list of server IDs was rotated at an unknown point. Find a given ID in O(log n).

Binary search on a rotated array. One half around mid is always sorted — check whether the target lies in it. Lesson: Rotated sorted array

Packages with weights must ship in the given order within D days. Find the smallest ship capacity that works.

Binary search on the answer. "Smallest capacity such that…" with a yes/no check that flips once. Lesson: Binary search on the answer

Every ID in a log appears twice except one. Find it with O(1) extra memory.

Bit trick: XOR everything. a ^ a = 0, so pairs cancel and the single one is left. Lesson: Bit tricks

Calendar entries have start and end times. Merge all entries that overlap.

Intervals: sort by start, merge. Once sorted, only the last kept interval can overlap the next one. Lesson: Intervals

Check whether a binary tree is a valid binary search tree.

BST with (low, high) bounds. Each node must fit the range set by all its ancestors, not just its parent. Lesson: Binary search tree

Place n security guards on an n × n board so no two share a row, column or diagonal. Count the ways.

Backtracking (N-Queens). One per row; column and diagonal sets make each check O(1). Lesson: N-Queens

A robot moves only right or down on a grid with some blocked cells. Count its paths to the bottom-right.

Grid DP. Each cell = paths from above + paths from the left (0 if blocked). Lesson: Grid DP

Group a list of product names into groups that are anagrams of each other.

Hashing (sorted word or letter count as key). Same letters → same key → same bucket. Lesson: Arrays & hashing

Can a list of job durations be split between two workers so both work exactly the same total?

0/1 knapsack (subset sum). Pick a subset summing to total / 2, each job used once. Lesson: Knapsack (0/1)

A delivery app knows where every driver is. Return the k drivers closest to a restaurant.

Top K (max-heap of size k) or quickselect. "k closest" = keep only k candidates, throwing out the farthest. Lesson: Top K, Quick sort & quickselect

An array has only 0s, 1s and 2s. Sort it in one pass with no extra memory.

Dutch national flag (in-place, three pointers). Three values → three regions maintained by lo, mid, hi. Lesson: In-place tricks

As a user types in a search box, show all saved words starting with what they typed.

Trie. Prefix lookups across many words. Lesson: Trie (prefix tree)

Change "hit" into "cog" one letter at a time, every step a real word. Find the fewest steps.

BFS on an implicit graph. Words are nodes, one-letter changes are edges; fewest steps = BFS. Lesson: Graph basics

For each window of k consecutive minutes, report the highest CPU reading.

Monotonic deque. Max of every sliding window in O(n). Lesson: Monotonic deque
