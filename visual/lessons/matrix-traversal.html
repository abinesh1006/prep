Matrix Traversal

Walk a 2D grid in an unusual order — a spiral, a rotation, a wipe, a staircase — by keeping a few boundary numbers and moving them inwards.

Time to learn: about 2 hours · Prerequisites: Two pointers, In-place tricks

When to use it — the signal

The input is an m × n matrix and the question says "spiral order", "rotate by 90 degrees in place", "if a cell is 0 set its whole row and column to 0", or "each row and each column is sorted — find a target". No graph search is needed: the order of visiting is fixed by the shape.

The idea in plain words

  • Spiral: keep four walls — top, bottom, left, right. Walk along the top wall, then move it down by one. Walk down the right wall, then move it left. Bottom wall right-to-left, move it up. Left wall bottom-to-top, move it right. Repeat until the walls cross. A 3 × 4 matrix is done after 12 cells.
  • Rotate 90° clockwise = two simple moves. Transpose (flip across the main diagonal, so row i becomes column i), then reverse each row. In place means without making a copy — just swaps.
  • Set zeroes: you cannot wipe while scanning, or new zeros would wipe even more. First remember which rows and columns contain a zero, then wipe in a second pass.
  • Sorted rows and columns: stand at the top-right corner. Everything to your left is smaller, everything below is bigger. Too big → step left (that whole column is too big). Too small → step down (that whole row is too small). At most m + n steps.
Analogy

Spiral order is peeling an orange in one long strip: go around the outside, then the ring inside it, and so on. The staircase search is walking down a staircase in a dark building where each step tells you "too high" or "too low" — you only ever go left or down, never back.

Why it works

"Spiral: the four walls shrink by one after each side, so each cell is added exactly once — O(m·n)." "Rotate: a 90° clockwise turn sends (i, j) to (j, n−1−i); transpose does (i, j) → (j, i) and reversing the row does the n−1−i part." "Staircase: from the top-right, one comparison rules out a whole row or a whole column, so at most m + n steps."

The template to remember

// Spiral: four walls, shrink after each side
while (top <= bot && left <= right) {
    top row  → top++;     right col → right--;
    if (top <= bot)    bottom row ← bot--;
    if (left <= right) left col ↑  left++;
}
// Rotate clockwise = transpose + reverse rows
// (counter-clockwise = transpose + reverse columns)
// Staircase: start top-right
if (v > target) c--; else r++;
Remember

Spiral = four walls. Rotate = transpose + reverse. Zeroes = remember, then wipe. Sorted grid = start top-right.

Common mistakes
  • Spiral: forgetting the if (top <= bot) / if (left <= right) checks — a single middle row is then added twice.
  • Transposing the full matrix (j from 0) — every pair swaps twice and nothing changes. Start j at i + 1.
  • Set zeroes: wiping during the first scan.
  • Staircase from the top-left: both moves (right, down) make the number bigger, so you cannot decide which way to go.

Test yourself

How do you rotate 90° counter-clockwise?

Transpose, then reverse each column (or: reverse each row first, then transpose).

In the staircase search, why not start at the top-left?

From the top-left both neighbours are bigger, so a comparison does not tell you which direction to move. Top-right (or bottom-left) has one smaller and one bigger direction.

How does Set Matrix Zeroes get O(1) extra memory?

Use row 0 and column 0 as the "has a zero" marks, plus one extra boolean for whether row 0 itself (or column 0) originally had a zero. Wipe the inner cells first, then row 0 and column 0 last.
