LCS & Edit Distance

Two strings → one 2D table: cell (i, j) answers the question for the first i letters of one string and the first j letters of the other.

Time to learn: about 3 hours · Prerequisites: DP intro, LIS

When to use it — the signal

Two strings (or two arrays) and a question about how they line up: "longest common subsequence", "minimum operations to convert word1 into word2", "minimum deletions to make them equal", "is s an interleaving of a and b", "distinct subsequences".

The idea in plain words

LCS (longest common subsequence): the longest sequence of letters that appears in both strings in the same order, gaps allowed. For "ace" and "abcde" it is "ace", length 3.

Let dp[i][j] = LCS of the first i letters of a and the first j letters of b. Row 0 and column 0 mean "empty string", so they are all 0. Then look at the last letters of the two prefixes:

  • Same letter → it belongs to the LCS: dp[i][j] = dp[i−1][j−1] + 1 (from the cell diagonally up-left, ↖).
  • Different → at least one of them is not used. Drop a's letter (cell above, ↑) or b's letter (cell to the left, ←), whichever gives more.

Every cell needs only the cell above, to the left and up-left, so we fill row by row, left to right. Remembering which arrow won lets us walk back from the bottom-right corner and read off the actual LCS.

Edit distance uses the same table with a different question: the fewest single-letter operations to turn word1 into word2. The three neighbours are the three operations: ↖ replace (or free if the letters match), ↑ delete a letter of word1, ← insert a letter of word2. Take the cheapest + 1.

Analogy

Comparing two versions of a document, like a "track changes" view: you want to keep as much as possible in common (LCS) and use the fewest edits (edit distance). The table is you reading both versions with one finger each; each cell is "how far have both fingers got".

2. Edit distance: "horse" → "ros"

Row i = first i letters of "horse", column j = first j letters of "ros". Each neighbour is one operation:

  • ↖ replace word1's letter with word2's (cost 1, or 0 if they already match),
  • ↑ delete word1's letter (cost 1),
  • ← insert word2's letter (cost 1).

Why it works

"Any alignment of two prefixes ends in one of three ways: both last letters are used together, or the last letter of one string is left out. Each case reduces to a smaller pair of prefixes that is already in the table, so taking the best of those cases is optimal. The table has (m+1)(n+1) cells with O(1) work each."

The template to remember

int[][] dp = new int[m + 1][n + 1];        // +1: row/col 0 = empty prefix
// fill row 0 and column 0 (base cases)
for (int i = 1; i <= m; i++)
    for (int j = 1; j <= n; j++)
        if (a.charAt(i-1) == b.charAt(j-1)) dp[i][j] = f(dp[i-1][j-1]);      // ↖
        else dp[i][j] = g(dp[i-1][j-1], dp[i-1][j], dp[i][j-1]); // ↖ ↑ ←

Two-string DP is one 2D table whose extra row and column stand for the empty string. Only the previous row is ever read, so it can shrink to two 1D arrays.

Remember

Two strings → (m+1) × (n+1) table, look at the last letters. ↖ match/replace, ↑ delete, ← insert.

Common mistakes
  • Off-by-one: dp[i][j] is about the first i letters, so the letter is charAt(i − 1).
  • Forgetting the base row and column in edit distance (they are 0..m and 0..n, not 0).
  • Confusing subsequence (gaps allowed — LCS) with substring (no gaps — reset to 0 on a mismatch).
  • Memory: only the previous row is needed; two rows of length n + 1 are enough when you do not need to walk back.

Practice in this order

  • Medium1143. Longest Common Subsequence — the first animation.
    Show solution

    The idea

    Length of the longest sequence of letters appearing in both strings in the same order (gaps allowed). "abcde", "ace" → 3. dp[i][j] = answer for the first i letters of a and the first j of b. If the last letters match, they extend the diagonal: dp[i-1][j-1] + 1. Otherwise drop one last letter: max(dp[i-1][j], dp[i][j-1]). Pattern: 2-D string DP.

    Brute force first

    Try every subsequence of one string against the other: O(2m · n).

    Step by step

    1. Make a (m+1)×(n+1) table; row 0 and column 0 stand for the empty string and stay 0.
    2. Fill row by row.
    3. Match: diagonal + 1. No match: max of up and left.
    4. Answer at dp[m][n].

    Java

    class Solution {
    public int longestCommonSubsequence(String a,
                                        String b) {
        int m = a.length(), n = b.length();
        // dp[i][j] = LCS of a's first i chars
        //            and b's first j chars
        int[][] dp = new int[m + 1][n + 1]; // row 0 = ""
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (a.charAt(i - 1) == b.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1; // ↖ +1
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], // ↑
                                        dp[i][j - 1]); // ←
                }
            }
        }
        return dp[m][n];
    }
}

    Time O(m · n) · Space O(m · n) — one cell per pair of prefixes (can be cut to one row).

    Dry run

    a = "abc", b = "ac": row 'a': [1,1]; row 'b': [1,1]; row 'c': 'c' = 'c' → diagonal 1 + 1 = 2. Answer 2.

    Watch out

    The table is one bigger than the strings, so letters are charAt(i-1), charAt(j-1). Subsequence ≠ substring: gaps are fine.

  • Medium583. Delete Operation for Two Strings — m + n − 2 × LCS.
    Show solution

    The idea

    Fewest single-letter deletions (from either word) to make the two words equal. What survives is a common subsequence, and to delete as little as possible keep the longest one. So the answer is m + n − 2 × LCS. Pattern: reduce to LCS.

    Step by step

    1. Fill the LCS table exactly as in problem 1143.
    2. Every letter not in the LCS gets deleted: m − LCS from the first word, n − LCS from the second.
    3. Return m + n − 2 × LCS.

    Java

    class Solution {
    public int minDistance(String a, String b) {
        int m = a.length(), n = b.length();
        int[][] dp = new int[m + 1][n + 1];   // LCS table
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (a.charAt(i - 1) == b.charAt(j - 1))
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                else
                    dp[i][j] = Math.max(dp[i - 1][j],
                                        dp[i][j - 1]);
            }
        }
        // keep the LCS, delete everything else in both
        return m + n - 2 * dp[m][n];
    }
}

    Time O(m · n) · Space O(m · n) — the LCS table.

    Dry run

    "sea", "eat": LCS = "ea" = 2. 3 + 3 − 4 = 2 (delete 's' and 't').

    Watch out

    This is not Edit Distance: only deletions are allowed, no replace. Two words with nothing in common need m + n deletions.

  • Medium72. Edit Distance — the second animation.
    Show solution

    The idea

    Fewest insert / delete / replace operations to turn word a into word b. "horse" → "ros" = 3. dp[i][j] = edits for the first i letters of a into the first j of b. If the last letters match, they cost nothing: dp[i-1][j-1]. Otherwise 1 + the cheapest of replace (↖), delete (↑), insert (←). Pattern: 2-D string DP (Levenshtein distance).

    Step by step

    1. Row 0: dp[0][j] = j (insert j letters). Column 0: dp[i][0] = i (delete i letters).
    2. Fill the rest row by row.
    3. Match: copy the diagonal.
    4. No match: 1 + min(diagonal, up, left).
    5. Answer at dp[m][n].

    Java

    class Solution {
    public int minDistance(String a, String b) {
        int m = a.length(), n = b.length();
        // dp[i][j] = edits to turn the first i chars of a
        //            into the first j chars of b
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 0; i <= m; i++) dp[i][0] = i; // delete
        for (int j = 0; j <= n; j++) dp[0][j] = j; // insert
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (a.charAt(i - 1) == b.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];   // free
                } else {
                    dp[i][j] = 1 + Math.min(
                        dp[i - 1][j - 1], // replace
                        Math.min(dp[i - 1][j],     // delete
                                 dp[i][j - 1]));   // insert
                }
            }
        }
        return dp[m][n];
    }
}

    Time O(m · n) · Space O(m · n) — one cell per pair of prefixes.

    Dry run

    "horse" → "ros": replace h→r (rorse), delete r (rose), delete e (ros). The table cell dp[5][3] = 3.

    Watch out

    Forgetting the first row and column (they are not 0) is the classic bug. Empty word → answer is the other word's length.

  • Medium516. Longest Palindromic Subsequence — LCS of s and reverse(s).
    Show solution

    The idea

    Longest subsequence of s that reads the same backwards. "bbbab" → "bbbb" = 4. A palindrome subsequence appears in s and, in the same order, in reverse(s). So the answer is the LCS of s and its reverse. Pattern: reduce to LCS (an interval DP dp[i][j] on s[i..j] also works).

    Step by step

    1. Build r = reverse(s).
    2. Fill the LCS table of s and r.
    3. Return dp[n][n].

    Java

    class Solution {
    public int longestPalindromeSubseq(String s) {
        String r = new StringBuilder(s).reverse().toString();
        int n = s.length();
        // a palindrome reads the same both ways, so it is
        // a common subsequence of s and reverse(s)
        int[][] dp = new int[n + 1][n + 1];
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                if (s.charAt(i - 1) == r.charAt(j - 1))
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                else
                    dp[i][j] = Math.max(dp[i - 1][j],
                                        dp[i][j - 1]);
            }
        }
        return dp[n][n];
    }
}

    Time O(n2) · Space O(n2) — an n×n LCS table.

    Dry run

    s = "cbbd", r = "dbbc". Common: "bb" → 2.

    Watch out

    This trick works for the longest palindromic subsequence, not for the longest palindromic substring (problem 5), where it can give wrong answers.

  • Medium97. Interleaving String — boolean table, take the next letter from a or b.
    Show solution

    The idea

    Can s3 be made by weaving s1 and s2 together while keeping each one's letter order? ok[i][j] = the first i letters of s1 and first j of s2 can form the first i+j of s3. The last letter of that s3 prefix came from s1 (then ok[i−1][j] must hold and the letters match) or from s2 (ok[i][j−1]). Pattern: 2-D boolean string DP.

    Brute force first

    Recursively take the next letter from s1 or s2 whenever it matches: O(2m+n) without memo.

    Step by step

    1. If the lengths do not add up, return false.
    2. ok[0][0] = true.
    3. For every (i, j) other than (0,0), let want = s3[i+j-1].
    4. ok[i][j] = (ok[i−1][j] and s1[i−1] == want) or (ok[i][j−1] and s2[j−1] == want).
    5. Return ok[m][n].

    Java

    class Solution {
    public boolean isInterleave(String s1, String s2,
                                String s3) {
        int m = s1.length(), n = s2.length();
        if (m + n != s3.length()) return false;
        // ok[i][j] = first i of s1 + first j of s2 can
        //            weave into the first i+j of s3
        boolean[][] ok = new boolean[m + 1][n + 1];
        ok[0][0] = true;
        for (int i = 0; i <= m; i++) {
            for (int j = 0; j <= n; j++) {
                if (i == 0 && j == 0) continue;  // base
                char want = s3.charAt(i + j - 1);
                if (i > 0 && ok[i - 1][j]
                        && s1.charAt(i - 1) == want)
                    ok[i][j] = true; // last letter from s1
                if (j > 0 && ok[i][j - 1]
                        && s2.charAt(j - 1) == want)
                    ok[i][j] = true; // last letter from s2
            }
        }
        return ok[m][n];
    }
}

    Time O(m · n) · Space O(m · n) — one cell per (i, j) pair.

    Dry run

    s1 "a", s2 "b", s3 "ab": ok[1][0] ('a'='a') T; ok[1][1]: from s2, ok[1][0] T and 'b'='b' → T.

    Watch out

    Check m + n == s3.length() first, or charAt may go out of range. A greedy "take from s1 when it matches" fails when both strings offer the same letter.

  • Hard115. Distinct Subsequences — count: on a match, add ↖ and ↑.
    Show solution

    The idea

    Count in how many ways t appears as a subsequence of s. s = "rabbbit", t = "rabbit" → 3 (pick which 'b' to skip). dp[i][j] = ways for the first i of s and first j of t. Letter s[i−1] can be skipped (dp[i−1][j], the ↑ cell); if it equals t[j−1] it can also be used (add dp[i−1][j−1], the ↖ cell). Pattern: 2-D counting DP.

    Step by step

    1. dp[i][0] = 1 for every i: the empty t appears once.
    2. dp[0][j] = 0 for j > 0.
    3. Fill row by row: start with dp[i−1][j]; if the letters match, add dp[i−1][j−1].
    4. Return dp[m][n].

    Java

    class Solution {
    public int numDistinct(String s, String t) {
        int m = s.length(), n = t.length();
        // dp[i][j] = ways the first i of s contain
        //            the first j of t as a subsequence
        long[][] dp = new long[m + 1][n + 1];
        for (int i = 0; i <= m; i++) dp[i][0] = 1; // t=""
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                dp[i][j] = dp[i - 1][j];   // skip s[i-1]
                if (s.charAt(i - 1) == t.charAt(j - 1))
                    dp[i][j] += dp[i - 1][j - 1]; // use it
            }
        }
        return (int) dp[m][n];
    }
}

    Time O(m · n) · Space O(m · n) — one cell per pair of prefixes.

    Dry run

    s "abb", t "ab": dp for t-prefix "a": rows 1,1,1. "ab": row 'b'(1st) = 0 + 1 = 1; row 'b'(2nd) = 1 + 1 = 2. Answer 2.

    Watch out

    Counts can be huge in the middle of the table even when the answer fits an int; the code uses long and casts at the end (wrapping is harmless here since only additions are used).

Test yourself

Why is the table (m+1) × (n+1) and not m × n?

Row 0 and column 0 stand for the empty prefix. They hold the base cases, so the recurrence never has to check for index −1.

In edit distance, which neighbour means "insert"?

The left one, dp[i][j−1]: we already turned a[0..i) into b[0..j−1), then insert b's letter j−1 at the end.

What is the edit distance from "abc" to ""?

3 — delete every letter. That is the base column: dp[3][0] = 3.
